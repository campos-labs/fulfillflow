External Carrier simulator

This page is instructional. It does not execute the simulator or receive secrets.

HTTP 202 means durable acceptance. The simulator polls for completion for up to 30 seconds; an observation timeout does not mean rejection or loss. Use --completion-timeout-seconds to change this limit, or --mode synchronous for frozen v1.1 images.

Carrier Alpha

carrier-alpha uses its own synthetic environment secret.

$env:CARRIER_ALPHA_WEBHOOK_SECRET="<set-locally>"
uv run python scripts/simulate_carrier_events.py `
  --base-url http://127.0.0.1:8000 `
  --carrier carrier-alpha `
  --tracking-code ALPHA000001 `
  --scenario valid

Normative scenarios

valid
Full POSTED → IN_TRANSIT → OUT_FOR_DELIVERY → DELIVERED flow.
duplicate
Repeats the complete signed request artifact and expects DUPLICATE.
out-of-order
Sends an older event second and expects IGNORED_STALE.
unknown-status
Expects HTTP 422 and UNKNOWN_EXTERNAL_STATUS.
invalid-signature
Expects HTTP 401 and INVALID_WEBHOOK_SIGNATURE.
